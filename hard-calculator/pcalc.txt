To do the pascal program we need the following rules 

01. program -> PROGRAM ID ';' declarations compound_statement '.'
02. declarations -> declarations VAR identifier_list ':' type ';'
03. identifier_list -> ID
04. type -> standard_type
05. standard_type -> INTEGER
06. compound_statement -> BEGIN optional_statements END
07. optional_statements -> statement_list
08. statement_list -> statement
09. statement -> variable ASSIGNOP expression
10. variable -> ID
11. expression -> simple_expression
13. simple_expression -> simple_expression ADDOP term
14. simple_expression -> term
15. term -> term MULOP factor
16. term -> factor
17. factor -> '(' expression ')'
18. factor -> NUM
